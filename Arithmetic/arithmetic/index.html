General instructions

Read this once. The clock starts when you press Begin.

This is a sectional paper, not a full mock. It behaves like one section of the real exam and it is scored the same way.

Duration
40 minutes, counted down on screen. When it reaches zero the paper submits itself — whatever is on screen at that moment is recorded.
Questions
22, shown one at a time. You may move between them freely using the palette on the right, in any order, as often as you like.
Marking
Multiple choice: +3 correct, −1 wrong. TITA questions carry no negative marking — every TITA answer is a whole number, so enter digits only.
Navigation
Save & Next records your answer and moves on. Mark for Review flags a question you intend to return to; a marked question is still graded if it carries an answer. Clear Response empties it.
Keyboard
1–4 select an option, Enter save and next, ← → move between questions, M mark for review.
What is recorded
Time on every question, every visit, and every option you select or change. That is what the analysis at the end is built from, and it is worthless if you look anything up. Sit it as an exam.

The paper is longer than the clock, on purpose

At a strong candidate's pace these 22 questions need about 43 minutes. You have 40. Nobody is expected to attempt all of them. The report you get at the end spends as much space on the questions you should have left alone as on the ones you got wrong.
