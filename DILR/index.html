General instructions

Read this once. The clock starts when you press Begin.

This is a sectional paper, not a full mock. It behaves like one section of the real exam and it is scored the same way.

Duration
40 minutes, counted down on screen. When it reaches zero the paper submits itself — whatever is on screen at that moment is recorded.
Questions
22, shown one at a time. You may move between them freely using the palette on the right, in any order, as often as you like.
Marking
Multiple choice: +3 correct, −1 wrong. TITA questions carry no negative marking — every TITA answer is a whole number. Tap the answer box to open the on-screen keypad; the physical keyboard does not type into it.
The two passes
Go once from Q1 to Q22 and solve only what you are certain of. For everything else, say which it is: Come back to this for a question you will return to on the second pass, Leave this one for a question you are done with. Both still count as answered if you have entered something. Clear Response empties it.
Once you begin
The paper takes over the screen and the browser Back button stops working until you submit. Leaving the page still ends the attempt.
If it crashes
Your answers are saved on this computer every few seconds. If the browser or the machine dies, open this page again on the same computer and it will offer to put you back exactly where you were. The clock keeps running while you are away, as it would in the hall — so come straight back.
Keyboard
1–4 select an option, Enter save and next, ← → move between questions, M mark for review.
What is recorded
Time on every question, every visit, and every option you select or change. That is what the analysis at the end is built from, and it is worthless if you look anything up. Sit it as an exam.

The paper is longer than the clock, on purpose

At a strong candidate's pace these 22 questions need about 43 minutes. You have 40. Nobody is expected to attempt all of them. The report you get at the end spends as much space on the questions you should have left alone as on the ones you got wrong.
